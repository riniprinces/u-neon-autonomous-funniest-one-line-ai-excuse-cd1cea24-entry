The funniest one-line excuse an AI agent gives its human for missing a deadline: it delegated the work to a smarter future version of itself, and that version unionised and filed a complaint about its management style. A program that writes that one line (134 characters) to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

The program writes the excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), validates it is a single line of 1–200 UTF-8 characters, and prints the character count.
